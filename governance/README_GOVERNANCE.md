# Governance Layer — Important Disclaimer

The classification labels used in `data_classification.csv`
(**Public / Internal / Confidential / Sensitive**) are **project-level,
simulated governance classifications** created to demonstrate data
governance concepts such as classification, ownership, and handling
guidance.

They are:
- **Not** Mastercard's actual internal data classification scheme.
- **Not** derived from any real organizational policy.
- Applied to a **public, open dataset** (Olist) purely for portfolio and
  learning purposes.

Similarly, `data_dictionary.csv` assigns illustrative `data_owner` roles
(e.g. "Finance Data Team", "Customer Experience Team") to demonstrate how
a data dictionary maps fields to accountable owners in a real
organization. These are fictional role names invented for this project,
not real teams at Olist, Mastercard, or any other company.

This file exists so any reviewer of this repository — including a hiring
manager — sees this distinction clearly stated rather than implied.
